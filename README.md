# Temperature Conversion Web App

A **simple and interactive web application** that converts temperatures between **Celsius** and **Fahrenheit**.  
Designed with HTML, CSS, and JavaScript, this project is perfect for learning basic web development and practicing DOM manipulation.

---

## **Features**
- Convert **Celsius to Fahrenheit**.
- Convert **Fahrenheit to Celsius**.
- Real-time result display.
- User-friendly and visually appealing interface.

---

## **Technologies Used**
- **HTML** – Structure of the webpage
- **CSS** – Styling the form, buttons, and layout
- **JavaScript** – Temperature conversion logic

---

## **Usage**
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Enter a number in the input box.
4. Select the conversion unit:
   - **Celsius ➡ Fahrenheit**
   - **Fahrenheit ➡ Celsius**
5. Click **Submit** to see the converted temperature.

## **Example**
- Input: `100`, select **Celsius ➡ Fahrenheit** → Output: `212°F`
- Input: `32`, select **Fahrenheit ➡ Celsius** → Output: `0°C`
